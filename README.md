## Description

This program outputs a single-line, 115-character deadpan apology note from an exasperated office printer to its users—owning up to mangling an important document while delivering a dry critique of the user's font choice.

## Run it

```sh
node main.ts
```

The grader runs `node /bot/main.ts` inside a Node 22 sandbox with no network access. The program writes the UTF-8 single-line entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaulting to `/output/entry.txt`), sets file permissions to `0644`, prints nothing on success, and exits non-zero if validation or writing fails.
